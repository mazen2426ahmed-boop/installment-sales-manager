# برنامج إدارة البيع بالتقسيط

تطبيق سطح مكتب (Windows) لإدارة بيع الأجهزة الكهربائية والمنزلية بالتقسيط — يعمل بالكامل بدون إنترنت وتُحفظ البيانات محلياً.

## الميزات

- **إدارة العملاء**: إضافة وتعديل وحذف العملاء مع سجل كامل وبحث سريع.
- **المخزون والموردون**: إدارة المنتجات (موبايلات، غسالات، ثلاجات، بوتجازات…) بالبراندات والموردين وأسعار الشراء.
- **البيع بالتقسيط**: تسجيل عملية البيع مع:
  - سعر الشراء + هامش الربح (30٪–40٪ افتراضياً) لحساب سعر البيع.
  - دفع **مقدم** وتوزيع المتبقي على عدد أقساط (12 شهراً افتراضياً).
  - توليد تلقائي لجدول الأقساط بنفس اليوم من كل شهر ابتداءً من الشهر التالي.
- **متابعة الأقساط**: تسجيل السداد الكامل أو الدفعات الجزئية، ومتابعة المتبقي.
- **التنبيهات**:
  - الأقساط **المستحقة**.
  - الأقساط **المتأخرة أكثر من 90 يوماً** (تنبيه أحمر عاجل).
- **استيراد/تصدير Excel** للعملاء والمنتجات والمبيعات (مع قوالب جاهزة).
- **تقارير مالية تفصيلية** لفترة محددة قابلة للطباعة (مبيعات، مقدمات، محصّل، متبقٍ، أرباح).
- **نسخ احتياطي واسترجاع** لقاعدة البيانات.

## التقنيات

- Electron + React + TypeScript (واجهة عربية حديثة RTL).
- قاعدة بيانات SQLite محلية عبر `sql.js` (WASM — بدون أي مكتبات أصلية، تتسع لآلاف العملاء).
- `xlsx` لاستيراد وتصدير ملفات Excel.
- `recharts` للرسوم البيانية.

## التطوير

```bash
npm install
npm run dev          # تشغيل التطبيق في وضع التطوير
npm run typecheck    # فحص الأنواع
npm run lint         # فحص الكود
```

## بناء ملف التنصيب (Windows)

```bash
npm run build:win
```

يُنتج ملف التنصيب `إدارة البيع بالتقسيط-Setup-1.0.0.exe` داخل مجلد `dist/`.

> ملاحظة: بناء ملف تنصيب Windows من نظام Linux يتطلب وجود `wine`. يمكن أيضاً بناؤه مباشرة على جهاز Windows.

## مكان حفظ البيانات

تُحفظ قاعدة البيانات تلقائياً في مجلد بيانات المستخدم الخاص بالتطبيق:
- Windows: `%APPDATA%/installment-sales-manager/data.sqlite`
